## 📌 About The Project

**Sparsha Skin & ENT Hospital** is a modern responsive healthcare website
developed for a hospital in **Gajwel, Telangana**.

The website provides patients with easy access to:

- Hospital information
- Dermatology & Skin Care services
- ENT services
- Doctor information
- Hospital gallery
- Appointment booking
- Contact information
- Location details

The project is designed with a clean, professional and mobile-friendly
interface inspired by modern healthcare websites.

🚀 Getting Started
1. Clone the Repository
git clone https://github.com/YOUR_USERNAME/sparsha-hospital.git
2. Open the Project
cd sparsha-hospital
3. XAMPP Setup

Move the project into:

C:\xampp\htdocs\sparsha-hospital

Start the following services from XAMPP:

Apache
MySQL
4. Open the Website

Visit:

http://localhost/sparsha-hospital/
