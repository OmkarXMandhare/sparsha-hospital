# 🏥 Sparsha Skin & ENT Hospital Website

A modern, responsive hospital website built using **HTML5, CSS3, Bootstrap 5, JavaScript, PHP, and MySQL**. This project is designed for a local Skin & ENT hospital, providing patients with an easy way to learn about services, doctors, and book appointments online.

---

## 📌 Features

### 🌐 Frontend

- Modern Responsive Design
- Bootstrap 5 UI
- Mobile Friendly
- Hero Banner
- About Us
- Services
- Doctors
- Gallery
- Contact Page
- Appointment Booking Form
- Animated Counters
- Preloader
- Doctor Availability Section
- CSS Animations
- Font Awesome Icons

### ⚙ Backend (In Progress)

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/omkarxmandhare/sparsha-hospital.git
```

Open the project folder

```bash
cd sparsha-hospital
```

If using PHP:

1. Install XAMPP
2. Copy the project into

```
htdocs/
```

3. Start

- Apache
- MySQL

Open in browser

```
http://localhost/sparsha-hospital
```
